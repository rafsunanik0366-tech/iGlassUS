iGlassUS Cloudflare Auth + Secrets Store package

This version includes:
- D1 binding: DB -> iglass-production
- Static assets binding: ASSETS
- Secrets Store binding:
    ADMIN_SETUP_KEY
    Store ID: 29529621cfef4e34bbb8034920399e0e
    Secret name: ADMIN_SETUP_KEY

The secret VALUE is NOT stored in this project or GitHub.

After uploading these files to GitHub and Cloudflare redeploys:
1. Confirm deployment log shows:
   env.DB
   env.ASSETS
   env.ADMIN_SETUP_KEY
2. /api/test-db should still return users/vendors/sessions.
3. Then create the first admin through POST /api/auth/bootstrap-admin
   using header:
      X-Setup-Key: <your private ADMIN_SETUP_KEY value>
   and JSON body:
      {
        "username": "your-admin-username",
        "email": "your-email@example.com",
        "password": "at-least-12-characters"
      }

Do not put the ADMIN_SETUP_KEY value, admin password, or vendor passwords in GitHub or public/index.html.
