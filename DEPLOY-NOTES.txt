iGlassUS Cloudflare Full Package

Includes:
- public/index.html
- public/assets/
- src/index.js
- wrangler.jsonc
- D1 binding: DB -> iglass-production
- Static assets binding: ASSETS
- Secrets Store binding: ADMIN_SETUP_KEY
- Auth API
- Admin setup page

After uploading these files to GitHub and Cloudflare redeploys:

1. Test database:
   https://iglassus.rafsunanik0633.workers.dev/api/test-db

2. Test auth:
   https://iglassus.rafsunanik0633.workers.dev/api/auth/me
   Expected before login:
   {"ok":false,"error":"Not authenticated."}

3. Create the first Admin:
   https://iglassus.rafsunanik0633.workers.dev/admin-setup

4. Enter:
   - Admin username
   - Email
   - Password (12+ characters)
   - Your private ADMIN_SETUP_KEY

The Admin setup page disables itself after the first Admin account exists.

SECURITY:
- Do not put passwords or ADMIN_SETUP_KEY in GitHub.
- Passwords are hashed before storage in D1.
- Sessions use HttpOnly Secure cookies.
